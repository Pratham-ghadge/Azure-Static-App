========================================================
COMMON ERRORS AND SOLUTIONS
========================================================

--------------------------------------------------------
ERROR 1 — Permission Denied
--------------------------------------------------------

Problem:

Permission denied


Solution:

Run:

sudo chmod -R 755 /var/www/html

sudo chown -R www-data:www-data /var/www/html


========================================================
ERROR 2 — NGINX DEFAULT PAGE SHOWING
========================================================

Problem:

Browser shows:
Welcome to nginx


Solution:

Remove default nginx page:

sudo rm -f /var/www/html/index.nginx-debian.html


Restart nginx:

sudo systemctl restart nginx


========================================================
ERROR 3 — WEBSITE NOT OPENING
========================================================

Problem:

This site can’t be reached


Solution:

Check nginx status:

sudo systemctl status nginx


Restart nginx:

sudo systemctl restart nginx


Verify inbound rules:
- Port 80 must be open


========================================================
ERROR 4 — 404 NOT FOUND
========================================================

Problem:

404 Not Found


Solution:

Check files:

ls /var/www/html


Make sure:
index.html exists


If missing:

sudo nano /var/www/html/index.html


========================================================
ERROR 5 — CSS OR JS NOT WORKING
========================================================

Problem:

Website design broken


Solution:

Check files exist:

ls /var/www/html


Make sure:
- style.css exists
- script.js exists


Verify paths in HTML file.


Correct:

<link rel="stylesheet" href="style.css">

<script src="script.js"></script>


========================================================
ERROR 6 — NGINX FAILED TO START
========================================================

Problem:

Nginx service failed


Solution:

Check nginx config:

sudo nginx -t


Fix errors shown in terminal.


Restart nginx:

sudo systemctl restart nginx


========================================================
ERROR 7 — NANO EDITOR NOT WORKING
========================================================

Problem:

Nano editor broken


Solution:

Run:

export TERM=xterm


Then retry:

sudo nano index.html


========================================================
ERROR 8 — WEBSITE OPENS BUT IMAGES NOT SHOWING
========================================================

Problem:

Images missing


Solution:

Place images inside:

/var/www/html


Example:

/var/www/html/logo.png


Use correct image path:

<img src="logo.png">


========================================================
ERROR 9 — CHANGES NOT REFLECTING
========================================================

Problem:

Website still shows old content


Solution:

Restart nginx:

sudo systemctl restart nginx


Clear browser cache:
CTRL + SHIFT + R
